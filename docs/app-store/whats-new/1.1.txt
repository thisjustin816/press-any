Game Boy Printer
Games that print now work. The slip comes out of a drawn printer, and you can save or share it as a PNG with a transparent, light or dark background. The Wood, Printer, Game Artwork and Custom backgrounds and a longer print history are part of Plus. Prints are kept with each Game in Captures, and a Printer Log helps when a game does not print.

Game Boy Camera
Camera cartridges see through your iPhone's camera, with color capture on compatible ROMs. Choose the rear camera, the front camera or none in Settings or the game menu.

Tilt games
Cartridges with a motion sensor follow how you tilt your iPhone. Recenter Tilt is in the game menu.

Gameplay presets
Choose how games look and feel for each system, free: Nostalgic, the new default, is as you remember it, polished for today's screens. Accurate is as the original looked and felt, on its own screen or on the television a Super Game Boy or Game Boy Player played on. Clean is just the game, with no effects added. Plus lets you change each setting on its own. The Game Boy palettes stay free.

Games look different now
If you never changed how the screen looks, your games now use Nostalgic and its screen filter. For sharp, unfiltered pixels, choose Clean in Settings. Settings you chose yourself stay as they were.

Automatic hardware
Automatic now picks the hardware for each game, free: a Game Boy Color for color games and Nintendo's own games, a Super Game Boy 2 for Super Game Boy games, a Game Boy Advance for the games with extras there, and a Game Boy Pocket for the rest. A game with save states from an earlier version stays on the Game Boy or Game Boy Color they were made on, so they keep loading.

Model (Plus)
Run games on a Game Boy, Game Boy Pocket, Super Game Boy, Game Boy Color, Game Boy Advance or Game Boy Player, each with its own boot ROM.

Artwork
After you import a recognized game, Press Any can find its artwork and ask you to review what it found. Turn this off in Settings.
